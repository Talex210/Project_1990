# Бонусы и модификации

Статус: дизайн-черновик. На фазе 3 превратить в полную data-спецификацию (каждый эффект + тесты).

## Data-driven (кратко)

Бонус = запись в данных: id, буква/иконка, кто может взять, длительность, эффекты, отмена.  
Код не хардкодит «все буквы» вперемешку с физикой — только движок эффектов.

## Классика расширенной версии «с буквами»

В v1 реализуем **полный** набор механик мода (уточнить 1:1 по референсу при имплементации), включая как минимум:

| Идея | Смысл (типичный для мода) |
|------|---------------------------|
| Враги берут бонусы | Да, не только игрок |
| Звезда / апгрейд танка | Броня / сила / уровни танка |
| Пистолетик / оружие | Скорострельность / сила выстрела |
| Шлем | Временная неуязвимость |
| Часы | Заморозка врагов |
| Лопата | Укрепление стен у базы |
| Граната | Урон по всем/многим врагам на поле |
| Корабль / вода | Езда по воде |
| Сбривание леса | Пуля/танк убирает лес по правилам мода |
| Танк / жизнь | Extra life (если есть в референсе) |
| Прочие буквы референса | Закрыть чеклистом 1:1 на фазе 3 |

Точный список букв и правил — сверить с выбранным референсом расширенной Tank 1990 и зафиксировать таблицей «буква → эффект → тест».

## Свои модификации (предложения)

Цель: интереснее классики и устойчивее баланс на 100 уровнях.

| Id (черновик) | Идея | Зачем для баланса / интереса |
|---------------|------|------------------------------|
| `overheat` | Перегрев при спаме сильного оружия | Контр к бесконечному пистолетику |
| `repair_pad` | Ремзона на карте | Контроль точки, не только дуэль |
| `smoke` | Дым режет дальнюю стрельбу | Тактика, смена темпа |
| `decoy` | Приманка агро | Спасение базы без гранаты-имбы |
| `chain_mine` | Цепная мина с риском | High risk / high reward |
| `team_aura` | Бафф себе и ИИ-союзнику | Кооп с ботом осмысленнее |
| `greed_mark` | Метка на враге после серии бонусов | Читаемость + контр жадным врагам |
| `sudden_act` | Жёсткий акт на поздних уровнях | Давление без нечестного one-shot |

На фазе 3: выбрать 3–5 своих фич в первый заход, остальные — после баланса.

## Принципы баланса

1. Сильный эффект → есть ответ или цена.  
2. Рост сложности уровней = умнее/злее ИИ и состав волн, не только цифра HP.  
3. Враги с бонусами должны быть **читаемы** (визуал/звук).  
4. Каждый бонус = автотест правила.
