## Data-driven

Бонус = запись в данных: `id`, буква, кто может взять, длительность, эффекты, отмена, очки, группа исключения.  
Код не хардкодит «все буквы» вперемешку с физикой — только интерпретатор (`crates/sim/src/bonus.rs`).

Формат каталога: секции `[id]`, строки `key=value`, `#` комментарии (как `score.cfg`).  
Глобально: `drop_every_kills` (**4** в shipped-каталоге — каждый 4-й заспавненный враг мигающий носитель), `pickup_lifetime_secs`.  
Буква при дропе: **взвешенный random** (`weight` у каждой записи), не round-robin. Сильнее эффект → ниже вес.

| Ключ | Смысл |
|------|--------|
| `letter` | Символ на квадрате бонуса |
| `name` | Короткое имя для HUD (`H Helmet`) |
| `pickup_lifetime_secs` | (глобально) сколько секунд буква лежит на карте |
| `who` | `player` / `enemy` / `both` |
| `duration_secs` | `0` = мгновенный или до события cancel |
| `effects` | Список `EffectName` через запятую |
| `cancel` | `death`, `level_end` (через запятую) |
| `score` | Очки за подбор |
| `max_stacks` | Для `TankUpgrade` (звезда) |
| `exclusive_group` | Новый бонус группы снимает предыдущий |
| `weight` | Относительный шанс дропа (выше = чаще; default `1`) |

### Перенос между STAGE

| Что | Переносится? |
|-----|----------------|
| ★ / Gun (уровень 1…4) | Да, до смерти |
| Ship (B) | Да, до **попадания** вражеской пули (без таймера) |
| H / C / L | Нет (timed) |
| Буквы на поле | Нет |

Попадание при ★>0 → минус одна звезда (+ сброс Ship), не смерть. При ★0 → смерть (и сброс Ship).

### Эффекты (движок)

| EffectName | Смысл |
|------------|--------|
| `Invuln` | Временная неуязвимость |
| `FreezeOpponents` | Заморозка противоположной команды |
| `FortifyBase` | Стены у базы → сталь на время |
| `KillOpponents` | Уничтожить танки противоположной команды |
| `TankUpgrade` | +1 уровень танка (до 4) |
| `MaxUpgrade` | Пистолетик: 1-й → ★3, 2-й → ★4 (лес) |
| `ExtraLife` | Игрок: +1 жизнь. Враг (Tank 1990): все враги на поле получают броню |
| `WaterWalk` | Корабль (постоянный до попадания) |

Отдельной буквы леса **нет**.

### Уровни танка (звезда / пистолетик)

| Уровень | Оружие |
|---------|--------|
| 0 | Базовый fire |
| 1 | Быстрее перезарядка / пуля |
| 2 | До 2 пуль на поле |
| 3 | Ещё быстрее + пули ломают **сталь** |
| 4 | Как ★3 + пули сбривают **лес** (4-я ★ или 2-й P) |

## Классика «с буквами» (каталог v1)

| Id | Буква | Эффект | weight | Примечание |
|----|-------|--------|--------|------------|
| `star` | * | TankUpgrade | 12 | Самый частый — прогресс оружия |
| `helmet` | H | Invuln | 8 | Шлем |
| `ship` | B | WaterWalk | 7 | Корабль / вода |
| `shovel` | L | FortifyBase | 5 | Лопата |
| `clock` | C | FreezeOpponents | 8 | Часы |
| `tank` | T | ExtraLife | 3 | Игрок +жизнь; враг → броня всем |
| `gun` | P | MaxUpgrade | 2 | Пистолетик (редко) |
| `grenade` | G | KillOpponents | 2 | Граната (редко) |

Враги: **один** ближайший едет к букве по **BFS** (обход стен; без толпы). Полный ИИ — фаза 4.  
Часы (C): в классике NES ~**10 с**; у нас **`duration_secs=8`** (было 4 — коротковато с активным ИИ).  
Пули: **только** пуля игрока гасит пулю врага; враг↔враг не уничтожают друг друга.  
Лопата: если танк стоял в кольце фортификации — его **выталкивает** на свободную клетку.

| Буква у врага | Таймер? | Смысл |
|---------------|---------|--------|
| H | нет | Броня: +★ (мульти-хит), не god-mode |
| C | да (8 с) | Игрок не двигается, **может стрелять** |
| T | нет | **Все** враги на поле: броня (как Tank 1990 / «зелёные») |
| B | нет | Ship до попадания |
| ★ | нет | С первой ★ враг ломает **сталь** |
| P | нет | **Все** враги: броня + ломают сталь |
| L / G | мгновенно | Ослабить базу / убить оппонентов |

Читаемость: мигание носителя DROP белый/красный (+ чуть крупнее силуэт); броня (H/T) — зелёный blink + крупный корпус; ★ оранжевый / длинный ствол (у игрока золотой ствол); Ship — широкий «лодочный» силуэт + циан; HUD `ENEMY …`.

## Принципы баланса

1. Сильный эффект → есть ответ или цена.  
2. Рост сложности уровней = умнее/злее ИИ и состав волн, не только HP.  
3. Враги с бонусами **читаемы** (буква на поле + HUD).  
4. Каждый бонус = автотест правила (фаза 3.4).
