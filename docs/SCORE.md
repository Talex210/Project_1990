# Очки, жизни и мотивация скора

Статус: дизайн для фазы 2 (+ уточнение чисел на балансе). Всё — data-driven, с тестами.

## Базовые правила (классика + v1)

| Правило | Смысл |
|---------|--------|
| Очки за врагов | Разный тип танка → разный вес (лёгкий < бронированный < босс-волна) |
| Очки за бонусы | Подбор бонуса даёт очки; **перехват** бонуса у врага — повышенный вес |
| Clear level | Бонус за завершение уровня (база цела) |
| **Жизнь за порог** | Каждые `life_every_points` очков (черновик: **20 000**, как в классике) → **+1 жизнь** |
| Кап жизней | Опциональный максимум (data), чтобы не бесконечный запас на поздних уровнях |

Порог и кап — в конфиге, не в хардкоде. Событие «жизнь за очки» один раз на каждый пересечённый порог (накопительно за весь ран), с тестом на границы.

## Автоогонь (связь с комфортом, не со скором)

- Удержание кнопки огня = стрельба на текущем fire-rate.
- Toggle-клавиша автоогня (вкл/выкл) — как удобство классики/портов.
- Не обходит лимит пуль на поле и будущий перегрев.

## Мотивация зарабатывать очки (идеи)

Цель: скор — не просто цифра в углу, а повод играть рискованнее и чище.

### В v1 (приоритет)

1. **Жизнь за порог** — прямая выгода выжить и фармить аккуратно.
2. **Таблица рекордов по профилю** — лучший скор / лучший скор на уровне.
3. **Медали уровня** (бронза/серебро/золото) за пороги скора на уровне — видны в прогрессе.
4. **Стиль-множители (короткие):**
   - серия убийств без смерти (`streak`);
   - убийство врага с бонусом / до того, как враг донёс бонус до укрытия;
   - clear без урона по базе;
   - clear без потери жизни на уровне.
5. **«Жадный» бонус скора** — уничтожить врага, который только что взял бонус (контр жадным врагам + очки).

### Сразу после v1 / задел в данных

6. **Мягкие косметические разблокировки** за суммарный скор или медали (скин трассера, рамка профиля) — без pay-to-win.
7. **Ранговые звёзды профиля** от суммарных очков — видно в будущем сетевом лобби.
8. **Еженедельный seed-уровень** с отдельным leaderboard (сервер).
9. **Score wager** в коопе с союзником: общий банк очков за уровень → общий множитель (позже).

### Чего избегать

- Не покупать силу за очки в середине уровня (pay-to-win mid-run ломает Tank 1990).
- Не штрафовать новичка так, что без идеального скора нельзя пройти — медали/рекорды опциональны для прохождения, **жизни за порог** — основной «геймплейный» мотиватор.

## Тесты (минимум)

- Начисление очков по типам целей.
- Пересечение порога → ровно +1 жизнь; двойной порог за один фрейм → корректное число жизней.
- Стрик сбрасывается при смерти.
- Сейв хранит скор рана и рекорды профиля.
