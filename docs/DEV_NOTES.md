# Заметки по разработке

## Структура репозитория (фазы 0–1)

```
Cargo.toml                 # workspace
crates/sim/                # project1990-sim — headless логика + тесты
crates/game/               # project1990 — Bevy-окно, ввод, спрайты
data/maps/                 # level_001..003, placeholder, test_level (все 16×16)
                           # HQ (E): классика — низ карты, вплотную к нижней границе;
                           # кольцо сейчас сталь (S) для тестов; кирпич (#) — позже
data/levels/manifest.txt   # 100 stages → map + wave params
data/score.cfg             # таблица очков
.github/workflows/ci.yml   # cargo test --workspace
```

Правила тайлов: вода — только с Ship; лес проходим; сталь ломается с ★3+; лес сбривается с ★4 (4★ или 2×P); кирпич — всегда.

## UI / меню (фаза 2)

- **Одно окно** — норма для desktop-порта классики (не отдельные окна ОС).
- Сейчас: текстовое главное меню + пауза + экран **STAGE N** перед боем (жизни, скор, враги в волне, цель).
- Карта на Menu/STAGE скрыта, чтобы не путать с боем.
- **Title screen «как на Dendy»** (арт, шрифт, анимация START) — отложен на полировку (фаза 6); функциональный каркас уже есть.
- Перед каждым уровнем — STAGE-экран; на него же можно выводить подсказки/рекорды уровня позже.
- Оверлей — `Text2d` + `Anchor::TOP_CENTER` в полосе `HUD_BAND_PX` над картой (playfield сдвинут вниз); окно 1024×800. Адаптивный Bevy UI / свои шрифты — фаза 6.
- Кампания 1…100: `Campaign` в sim читает манифест; ранние карты уникальны, остальное — `placeholder.txt` + растущая волна. Уникальные раскладки — фаза 5.
- **GAME OVER** (база или 0 жизней) → рестарт рана с STAGE 01.
- **Отложено (2P / кооп):** игрок с 0 жизней по клавише старта может забрать 1 жизнь у второго игрока и снова выйти на поле (как в классике). Сейчас только соло — реализовать вместе с локальным P2 / ИИ-союзником.

## Чистый код: Rust + Bevy — так лучше для нас?

**Да, если цели такие, как у нас:** гибкость, тесты, сеть/сервер, много платформ позже.

| | Godot | Rust + Bevy (наш выбор) |
|--|-------|-------------------------|
| Скорость старта | Выше | Ниже (учить Rust + ECS) |
| Контроль и «всё в коде» | Средний | Высокий |
| `cargo test` / CI | Ок | Отлично |
| Headless-сервер | Возможно | Естественно вынести simulation |
| Desktop OS | Отлично | Отлично |
| Android / iOS / Web | Проще экспорт | Реалистично, но отдельная работа |

Итог: для «максимально универсально в будущем» Bevy — правильный долгосрочный ход. Цена — более жёсткая кривая обучения на старте.

## Data-driven бонусы — что это

Каталог: `data/bonuses/catalog.cfg`. Код: `crates/sim/src/bonus.rs` + `world.rs`.  
Дроп каждые `drop_every_kills` (**сейчас 4** в `data/bonuses/catalog.cfg` — не на каждом враге); буква выбирается **weighted random** (`weight` в каталоге: ★ часто, G/P редко). Враги seek’ят буквы по BFS. HUD: `ACTIVE` / `ON MAP` / `ENEMY`.  
Bevy: при новых `Query` в `crates/game` — взаимные `Without` (правило `.cursor/rules/bevy-query-without.mdc`), иначе B0001 на старте.  
Clock: классика ~10 с → у нас 4 с. Мигание носителей / брони восстановлено.  
После последнего врага — **clear grace 3 с** (HUD: `CLEAR! Ns`), потом Victory.  
**3.2 / 3.4 закрыты.** **3.3 свои моды — не сейчас** (см. ROADMAP / BONUSES.md).

## Feel / читаемость (после фазы 3)

- **Скорость танков:** `SimConfig.tank_speed = 2.0` тайла/с (пульсы `bullet_speed = 6.0`).
- **Направление:** ствол (child-спрайт) у всех танков; корпус чуть шире высоты.
- **Силуэты:** ★ → длиннее/толще ствол (+ золото у игрока); броня → крупнее корпус + зелёный blink у врага; Ship → широкий «лодочный» корпус + циан; носитель DROP → чуть крупнее + white/red blink.
- **Grid settle:** при движении поперечная ось выравнивается к центру тайла (hard snap если свободно, иначе лёгкий nudge) — меньше залипаний в коридорах.
- **SFX (примитив):** `SimSfx::{Shot, Explosion}` из sim → Bevy `Pitch` (синус). Нормальные семплы / громкость — фаза 6.
- **Hit-flash / death-freeze:** **не делаем** (мигание по попаданию сбивает чтение; короткая «пауза смерти» = freeze кадра на kill — тоже отложено; достаточно звука взрыва).

## Скорости типов врагов

`EnemyKind` (Basic / Armor / Boss) уже есть для **очков**, но все спавны сейчас `Basic` с одной `tank_speed`.  
**Разные скорости / профили типов — фаза 4** (вместе со составом волн и таблицей силы по уровню). Сейчас не внедряем half-baked: без микса спавнов множители скорости бесполезны.

Подробнее: [BONUSES.md](BONUSES.md).  
Gate: `cargo test -p project1990-sim --test phase3_bonuses --test phase3_exclusions`.

## На каком «движке» ИИ

Отдельного AI-движка нет. **Враг и союзник** — логика в `project1990-sim` (модуль `ai`) + шаг мира; Bevy только рисует:

- **Фаза 4.1 (есть):** цели `EnemyGoal` — Base / Player / Bonus / Cover / Bypass; приоритет Bonus → Cover(угроза) → Bypass(нет пути) → Base|Player по слоту (`slot % 3 == 0` → игрок).
- общие примитивы: путь (BFS), линия угрозы, оценка укрытия;
- дальше: анти-застревание (4.2), профили/уровень (4.3), `AllyBrain` (4.4);
- сила врага = f(номер уровня) из таблицы данных (уровни 1…100).

Gate 4.1: `cargo test -p project1990-sim --test phase4_goals`.

## Сложность

**Зафиксировано:** чем выше уровень, тем сильнее противник (агрессия, точность, бонусы, состав волн). Не «просто больше HP без ума».

## Тесты — gate

Весь логический код покрываем сразу.  
Следующая фаза роудмапа **только после** зелёного `cargo test` и DoD текущей.

Не блокируем этап из-за отсутствия теста на «красивость взрыва», но блокируем, если нет тестов на правила урона, бонусов, сейва, ИИ-приоритетов.

## Сейвы и рекорды (фаза 2.7)

- Модуль `crates/sim/src/save.rs`: `SaveData` / `Profile` / Solo `BoardEntry`, **schema=2**.
- Файл: `saves/save_v1.txt` (или `$PROJECT1990_SAVE_DIR/…`). Старые schema=1 сейвы не читаются — создать профиль заново.
- До **8** именованных профилей; имена уникальны (без учёта регистра); всегда пункт **Create new**.
- **Personal best** — лучший скор профиля. **Solo records** — общая таблица топ-**10** (имя, очки, STAGE); показывается из меню (R) и после GAME OVER.
- **Coop / 2P:** отдельная таблица позже (не смешивать с Solo); второй игрок — свой профиль или гостевое имя в coop-записи.
- Continue / New game / Records / Change player — **курсорное меню** (`>` + Up/Down + Enter); то же на выборе профиля.
- **Автосейв** (без клавиши Save): создание/выбор профиля, победа STAGE, GAME OVER, плюс запись при выходе из приложения (`AppExit`).
- Gate фазы 2: `cargo test -p project1990-sim --test phase2_gate`.

## Очки и автоогонь

- Автоогонь: удержание огня + toggle — комфорт классики, без читов по лимиту пуль.
- Жизнь за порог очков + стиль/медали — мотивация скора без pay-to-win mid-run.
- `starting_lives` / `max_lives` / `life_every_points` / `invuln_secs` — в `data/score.cfg` (не хардкод в Bevy). Раньше в клиенте ошибочно стояло `life_every_points=200` → жизнь каждые ~2 убийства.
- Детали: [SCORE.md](SCORE.md).

## Платформы и «поиграть с сервера»

| Вопрос | Ответ |
|--------|--------|
| Сервер, чтобы все играли по сети? | Да, в планах после v1: dedicated / headless simulation |
| Android / iPhone? | Да как цель универсальности; отдельный этап порта |
| Одна кодовая база? | Симуляция общая; UI/ввод/стор — адаптеры под платформу |

## Что не делаем в v1

Редактор уровней (только задел формата), реплеи, геймпад, обязательные палитры доступности.

## Суть процесса для новичка

1. Маленький срез → тесты → поиграл.  
2. Данные (уровни, бонусы, кривая сложности) отдельно от систем.  
3. Не писать «весь ИИ» до едущего танка.  
4. Полировка арта/звука ближе к релизу, ядро — раньше.
