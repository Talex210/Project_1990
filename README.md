# Project 1990

Современная игра в духе **Battle City / Tank 1990** (Dendy): танчики, база, бонусы, умный ИИ, генерация уровней. Первая платформа — **macOS**. Сетевая игра планируется позже.

Репозиторий: [github.com/Talex210/Project_1990](https://github.com/Talex210/Project_1990)

Фаза 0 — фундамент документации и репозитория. Игровой код появится на фазе 1 (см. [ROADMAP.md](ROADMAP.md)).

## Установка (пока документация)

### Требования

- macOS 12+ (рекомендуется актуальная)
- Git
- [Godot 4.x](https://godotengine.org/download) — когда появится папка проекта

### Клонирование

```bash
git clone https://github.com/Talex210/Project_1990.git
cd Project_1990
```

### Запуск (после фазы 1)

1. Установить Godot 4.
2. Открыть проект через `project.godot` (путь появится в этом README).
3. Нажать **F5** (Play) или собрать macOS-экспорт.

> Сейчас в репозитории ещё нет Godot-проекта — только планирование. Инструкция обновится в фазе 1.
