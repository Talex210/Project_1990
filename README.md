# Project 1990

Современная игра в духе **Battle City / Tank 1990** (Dendy): танчики, база, полный набор бонусов «с буквами», умный ИИ, **100 уровней**, сейвы и рекорды.  
Стек: **Rust + Bevy** (чистый код). v1 — **macOS**. Архитектура сразу под сеть, сервер и другие платформы.

Репозиторий: [github.com/Talex210/Project_1990](https://github.com/Talex210/Project_1990)

## Статус

Фазы 0–1 закрыты: симуляция + окно Bevy на macOS, `cargo test` зелёный. Дальше — фаза 2 ([ROADMAP.md](ROADMAP.md)).

## Установка

### Требования

- macOS 12+
- Git
- [Rust](https://rustup.rs/) stable (MSRV по Bevy 0.20: **1.97+**)

### Клонирование

```bash
git clone git@github.com:Talex210/Project_1990.git
cd Project_1990
```

### Запуск

```bash
cargo run --release -p project1990
cargo test --workspace
```

Workspace:

| Crate | Роль |
|-------|------|
| `crates/sim` (`project1990-sim`) | Чистая симуляция (тайлы, танк, пули, тесты) |
| `crates/game` (`project1990`) | Bevy-клиент: окно, ввод, отрисовка |
| `data/maps/test_level.txt` | Тестовая карта фазы 1 |

## Управление (v1)

| Действие | Клавиши |
|----------|---------|
| Движение | WASD / стрелки |
| Огонь | Space / J (удержание = повтор с fire-rate) |
| Автоогонь вкл/выкл | K / CapsLock |
| Пауза | Esc / P (фаза 2) |

Геймпад — после v1.

## Для игрока (кратко)

- Цель: защитить базу, пройти уровни (план — **100**).
- Чем выше уровень — тем сильнее враги.
- Можно играть с **ИИ-союзником** во втором слоте.
- **Автоогонь** как в классике; очки → **жизнь на пороге**; рекорды и медали — см. `docs/SCORE.md`.
- Профили, сохранение прогресса, таблица рекордов.
- Полный мод «с буквами» + оригинальные механики — см. `docs/BONUSES.md`.
